# Positioning Statement

Kivi is a voice interface that gets more yours the longer you use it. Every correction you make, every tone you set for a different app, every time you switch between Hindi and English mid sentence, none of that is overhead. It's training. Cloud dictation tools smooth your voice into something generic. Local tools hand you a blank slate and leave you to do all the setup yourself. Kivi does neither. It starts as a stranger and slowly turns into an extension of how you actually think, in the language you actually think in. It's built for people whose voice doesn't fit inside one language's box, and it should never turn into an assistant that talks back instead of writing for you.
